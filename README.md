# 共享单车空间索引库

我们做共享单车的调度后台，要按地图上的范围查车。现在是每次查询把几十万辆的位置全扫一遍，算距离排序再截取，单次要几百毫秒，高峰期一秒钟来几千次查询，机器直接跪。这次想自己写一个空间索引的库。

两种查询都要支持：给一个矩形，返回落在里面的车；给一个点和数量 k，返回最近的 k 辆。两种都要快，不能全表扫。距离相同的时候按编号排，顺序必须稳定。车是动的，索引要能动态增删，一辆车换位置就是删掉再插进去；更新频繁的时候不能越用越慢，也不能有内存泄漏，查询过几百万次之后索引里占的东西还是那么多。坐标一律用整数，别用浮点，不然同样的点在两台机器上算出来的距离不一样，排序就会飘。实现只用标准库，测试用 unittest。

仓库里只有这份说明和 samples/ 里的样例，代码从零写。

## 坐标口径

- 经纬度都乘 1000000 取整，单位是「微度」：`lat_e6`、`lon_e6`。
- 取值范围：`lat_e6 ∈ [-90000000, 90000000]`，`lon_e6 ∈ [-180000000, 180000000]`；样例都在中国范围内。
- 车辆编号是正整数，全局唯一。
- 距离用**平方欧氏距离**：`d² = (lat₁ − lat₂)² + (lon₁ − lon₂)²`，全程整数运算，不做纬度余弦校正。这个值只用来排序，不代表真实米数——口径固定了，排序才在两台机器上一致。

## 边界规则

- 矩形是**闭区间**：`min_lat ≤ lat ≤ max_lat` 且 `min_lon ≤ lon ≤ max_lon`。压在四条边上的点算在内，压在角上的也算。
- `min_lat > max_lat` 或 `min_lon > max_lon` 这种反向矩形视为空集，返回空列表，不报错。
- 矩形查询的结果按**编号升序**返回。
- 最近 k 辆按 `(距离平方, 编号)` 升序取前 k 个：距离相同按编号升序；`k ≤ 0` 返回空；不足 k 辆时返回全部。
- 同一位置停着多辆车：它们是不同编号，各自独立返回；在最近 k 辆里距离相同，靠编号决定先后。

## 查询接口

库对外提供这几个操作，样例用 ops 文件驱动（格式见下）：

| 操作 | 参数 | 返回 |
|---|---|---|
| `insert` | `id, lat_e6, lon_e6` | 无；编号已存在时报错 |
| `remove` | `id` | 无；编号不存在时报错 |
| `update` | `id, lat_e6, lon_e6` | 无；等价于删掉再插进去，编号不存在时报错 |
| `rect` | `min_lat, min_lon, max_lat, max_lon` | 编号升序列表 |
| `nearest` | `lat, lon, k` | 按 `(距离平方, 编号)` 升序的编号列表 |

## 复杂度与性能要求

| 操作 | 期望复杂度 | 说明 |
|---|---|---|
| `insert` / `remove` / `update` | `O(log n)` | 不许全表扫 |
| `rect` | `O(log n + m)` | `m` 是命中数量，不许扫全部点 |
| `nearest` | `O(log n + k log k)` | 不许先给全部点算距离再排序 |

另外：

- 五十万个点建索引不超过 **5 秒**（单线程、本机 SSD、只算建索引本身）；
- 单次查询不超过 **5 毫秒**（`k ≤ 100`，点规模五十万）；
- 索引常驻内存不超过 **200 MB**；
- **查询不改变索引占用**：几百万次查询之后索引里的数据和内存都不增长（不许把查询结果或访问路径缓存起来越堆越多）。

## 随机对拍要求

不管中间插入、删除、更新过多少次，两种查询的结果都必须和「把所有车扫一遍」的暴力实现**逐项一致**（包括顺序）。测试里要用随机数据随机操作做对拍，这条是硬要求。

## 样例

每组样例三个文件，一一对应：

```text
samples/case-N.points.csv     id,lat_e6,lon_e6        初始车辆（按行顺序插入）
samples/case-N.ops.csv        一行一个操作，见下
samples/case-N.expected.csv   一行一个查询的结果
```

ops 文件的每行（`#` 开头是注释）：

```text
insert,<id>,<lat_e6>,<lon_e6>
remove,<id>
update,<id>,<lat_e6>,<lon_e6>
rect,<min_lat>,<min_lon>,<max_lat>,<max_lon>
nearest,<lat>,<lon>,<k>
```

期望结果文件对**每个查询操作**给一行，序号从 1 开始只数查询（`rect` 与 `nearest`），格式是「序号 + 编号列表」，编号用逗号分隔；没有命中时写 `<序号>,-`：

```text
1,3,7,12
2,-
```

- case-1：11 辆车，含正好压在矩形边上、角上的点，以及距离完全并列的两辆车，覆盖闭区间、并列排序、反向矩形与空结果。
- case-2：动态增删改，含同一坐标停多辆车、删掉再插回、把车更新到别处，操作之间穿插查询。
- case-3：5000 辆车加 200 次随机查询与 60 次随机增删改，用来对拍与看量级。
- case-4：边界专项，四个角、四条边、单点矩形、反向矩形都各来一次。
